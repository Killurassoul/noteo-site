TABLEAU DE BORD

INSTALLER NOTEO

Une application de bureau, sans compte. Vos cours et vos notes restent sur votre ordinateur.

  1. 01Téléchargez l’installeur (132 Mo) et lancez-le. Windows peut afficher un avertissement SmartScreen : cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  2. 02Choisissez le dossier d’installation. Noteo crée un raccourci sur le bureau et dans le menu Démarrer.
  3. 03Ouvrez Paramètres et collez une clé API (Anthropic, OpenAI, Google, Mistral…) pour activer les fiches, l’assistant et les quiz. Le fournisseur est détecté automatiquement. Sans clé, la prise de notes et la bibliothèque fonctionnent normalement.
Télécharger l’installeur Notes de version

Configuration requise : Windows 10 ou 11, 64 bits, 4 Go de RAM, 400 Mo d’espace disque. Version 1.0.0.

CONFIDENTIALITÉ

Noteo est conçu pour fonctionner en local.

  1. 01Cours, notes, fiches et résultats sont stockés dans une base locale, sur votre poste. Aucun compte, aucun serveur Noteo.
  2. 02Les clés API sont chiffrées par le système d’exploitation (Windows DPAPI) et ne quittent jamais votre machine, sauf vers le fournisseur que vous avez choisi.
  3. 03Seules les demandes que vous lancez (fiche, question, quiz) envoient l’extrait de cours concerné à ce fournisseur. Aucune télémétrie.
  4. 04Compatible avec un modèle hébergé en interne : Ollama ou toute API compatible OpenAI, pour que rien ne sorte de votre réseau.
